Responsive utilities allow you to apply different styles at different screen sizes using mobile-first breakpoint prefixes. This means styles apply from that breakpoint upward.

This text grows with screen size!

// tailwind.config.js module.exports = { theme: { screens: { 'xs': '475px', 'sm': '640px', 'md': '768px', 'lg': '1024px', 'xl': '1280px', '2xl': '1536px', '3xl': '1920px', // Custom named breakpoints 'tablet': '768px', 'desktop': '1024px', }, }, }
Mobile-first: Start small, enhance for larger screens
This would be large on mobile, small on desktop
/* What Tailwind generates */ .text-sm { font-size: 0.875rem; } /* Base */ @media (min-width: 768px) { .md\:text-base { font-size: 1rem; } /* Overrides at 768px+ */ } @media (min-width: 1024px) { .lg\:text-lg { font-size: 1.125rem; } /* Overrides at 1024px+ */ }
